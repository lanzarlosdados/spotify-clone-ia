# Spotify Clone IA

Este es un clon simplificado de Spotify, creado para experimentar con herramientas de inteligencia artificial (IA).

## Objetivo
- Explorar y prototipar funciones impulsadas por IA (recomendación musical, generación de playlists, búsqueda semántica, asistentes dentro de la app).
- Aprender y documentar buenas prácticas integrando servicios de IA en una app tipo Spotify.

## Stack (previsto)
- iOS con Swift y SwiftUI.
- Spotify Web API para autenticación y catálogo.
- Servicios de IA/LLM (a definir según etapa).

## Estado
- En exploración y experimentación. El alcance puede cambiar con frecuencia.

## Nota
Este proyecto es solo para fines educativos y de experimentación. No guarda relación con Spotify AB ni utiliza marcas registradas con fines comerciales.
