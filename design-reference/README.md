# design-reference/

Screenshots reales de la app de Spotify, usados como referencia visual para
los snapshot tests (no se compilan ni se empaquetan en la app ni en los
targets de test — son solo insumo para `scripts/snapshot_reference_crop.py`).

Convención: `design-reference/<Feature>/<estado>.png`, por ejemplo
`design-reference/Home/default.png`, `design-reference/Player/playing.png`.
